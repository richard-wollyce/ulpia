A library that lives with you.

Ulpia is a library. Your notes, your decisions, your protocols: markdown files, in folders, in git, on your disk. Move the folder and everything moves with it.

Vesta is its librarian. Ask her a question and she answers with the files that should open, and no model reads your library to do it. When she is wrong, she says why, in words you can act on.

Which file holds the answer and which of your agents should give it are different questions, and each goes to the thing that is good at it. Finding the file is a lookup, and code does that exactly. Choosing the agent is a judgement about a subject, so a model does that one. It is handed your question, the roster, the file names Vesta found with the words that matched, and the one line at the top of each of those files where you said what it is for. Never the files themselves. It is a guest too: it reads a briefing at the door, never the shelves.

Then you hand those files to whatever model you like. Yours, running locally. Claude, through MCP. Something else next year. The memory outlives the model.

Watch her work.

Two independent scorers read every question: a keyword index built from your own map, and full text search over the content. The signal is not the score, it is the agreement. A file both scorers found is a hit. A file only one found is a guess, and Vesta says so.

When nothing matches, the base answers with its own vocabulary, so a miss teaches you what the library covers instead of teaching you to stop asking.

And when a subject belongs to nobody in your fleet, Vesta says exactly that: nothing in this fleet covers it, which is a gap in the fleet rather than a gap in your question. No score can produce that sentence, and it is how you learn an agent is missing.

The other trade.

Most memory layers put an embedding model between you and your own notes. That buys semantic matching, and it costs four things: you cannot run it offline, you cannot explain a bad result, you cannot reproduce yesterday's answer, and your notes have been somewhere you did not choose.

Ulpia takes the other trade.

  • Offline, because your files are read on your machine and nowhere else.
  • Explainable, because every answer names the reason it was chosen.
  • Reproducible, because the same question finds the same files, today and in a year.
  • Private, because what git does not track, Vesta will not serve.

Choosing which agent answers is the one step that can call a model, and it calls a command you name, which you can swap or remove. A model may stand between you and your fleet. Never between you and your notes.

Where it stands.

Early, used daily, and honest about which is which. The core is tested. The tray app is young. The model that picks which agent answers takes seconds, and moving it onto your own machine is the work in front of us. The code is open source under Apache 2.0. The licence gives you the code with attribution kept; the name Ulpia stays ours, which is what makes both promises honest.

Why Ulpia?

Named for the Bibliotheca Ulpia, Trajan's library: Rome's reading room and its record office in one building.

No cookies, no analytics, nothing loaded from anyone else.

This page sets no cookies and runs no analytics. Everything it loads comes from ulpia.io: the styles, the fonts, the small scripts. Open the network tab and you will not find another origin.

It makes exactly one request that loading the page did not make, and only if you ask for it: when you submit the form, your address is posted to ulpia.io and stored so that we can write to you. Nothing else goes with it. If you never submit that form, this page never speaks to us at all.

The button copies our address to your clipboard when you press it. It writes; it never reads.

If you choose a light or dark scheme, that choice is kept in your browser's local storage and never leaves your machine.

The page is served by Cloudflare Pages, which means Cloudflare terminates TLS and sees the request, as it does for a large part of the web. That is the one third party in the path and we would rather name it here than have you find it.

What happens to an address afterwards is in the privacy notice. The product holds the same position as the page.
